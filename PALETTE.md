# Color palette

The base colors were approximately sampled from a pastel illustration supplied during development. These values are visual references, not an official palette from its illustrator. The source image is not bundled.

| Color | HEX | Use |
| --- | --- | --- |
| Cream | `#FDF9F0` | Stone paths, stair treads, arch trim, UI panels |
| Mint | `#D2F1E1` | Garden towers and bridge variants |
| Sky blue | `#C1DEE8` | Cloud platforms and lower courtyard |
| Strawberry | `#F5BCBD` | Towers and bridge variants |
| Lavender | `#E1D5EF` | Moon pavilion, lift, upper bridge |
| Butter | `#F2E5C1` | Light accents |
| Cocoa | `#674D5B` | Traveler hat and face |
| Peach cream | `#FAEADA` | Exit towers |

Derived accents include leaf green `#91BCAE`, recessed-window purple `#AC95B6`, honey brass `#CDA668`, and rose scarf `#C77F9C`.

The current water uses deeper lavender `#C2B0DC` (or pink `#DEB2C0` in chapter three), blue `#9CCDDB`, and mint `#AFD7BF`. Directional lighting and cool ambient fill separate architectural faces. Blender converts sRGB material values to linear space before GLB export; rendered colors therefore vary with lighting.
