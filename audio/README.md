# Light on Water

An original, locally synthesized instrumental loop: **60 seconds at 64 BPM**, with soft keyboard tones, plucked arpeggios, and sustained chords. No vocals, drums, external recordings, or instrument samples.

Run `compose_music.py` to regenerate `../assets/courtyard_music.wav` (Python, NumPy, and SciPy required). Note and reverberation tails wrap across the loop boundary.

The game uses a dedicated music player that persists across chapter changes. It fades in on launch and ducks gently beneath mechanism, collection, and completion effects. The sound icon or **M** toggles all audio.
